## Журнал решений
- 2026-09-16 — **Решили:** вход в кабинет партии закрыт, пока у партии не задан пароль
  (fail-closed). **Почему:** «мягкий» вариант (пускать без пароля, пока админ не выдал)
  оставляет дыру на неопределённый срок. **Цена:** после выкатки инженеры входят только
  после массовой выдачи паролей админом — это одна кнопка.
- 2026-09-16 — **Решили:** вход запоминать подписанной ссылкой (HMAC, ключ — хэш пароля
  партии), а не хранить пароль в адресной строке. **Почему:** Streamlit теряет состояние
  при F5, без ссылки пароль пришлось бы вводить каждый раз (особенно на телефоне), а
  хранить сам пароль в URL нельзя. Смена пароля партии аннулирует старые ссылки —
  удобный способ разом отключить выбывших.
- 2026-09-16 — **Решили:** тесты писать на `streamlit.testing.v1.AppTest` и отдельной
  временной базе. **Почему:** интерфейс Streamlit иначе не проверить без браузера,
  а гонять тесты по рабочей базе нельзя. Ограничение AppTest: между прогонами он не
  возвращает приложению параметры ссылки — в тестах их переносим руками (в браузере
  они сохраняются сами).
- 2026-09-09 — **Решили:** памятка инженера = текстовый документ для рассылки в
  чат/Word, а не вкладка в приложении. **Почему:** инженерам нужна инструкция до
  первого входа, а не подсказка внутри. **Альтернативы:** вкладка «Инструкция» в
  Streamlit (отложено).
- 2026-09-09 — **Решили:** формат инструкции со скриншотами — самодостаточный
  HTML (base64-картинки) + PDF из него через headless Edge. **Почему:** ноль новых
  зависимостей (python-docx не установлен), один файл переносится куда угодно.
  **Альтернативы:** .docx через python-docx (нужна установка — по согласию).
